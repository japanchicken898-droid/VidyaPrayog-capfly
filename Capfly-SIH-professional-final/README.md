# Capfly SIH – Professional BlueLearn-Inspired UI

A React + Vite frontend prototype for the SIH problem statement: academia–industry collaboration for skill mapping, internships, and placement.

## Included workspaces
- Student
- Academia / Faculty
- Industry
- Institution

## Main demo flow
Skill requirements → Skill assessment → Skill-gap analysis → Learning/readiness → Internship matching → Placement tracking.

## Run locally

Requirements: Node.js 18+ (Node.js 20+ recommended).

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Notes
This package is a frontend demonstration. Data and some integrations are demo/mock data; production deployment would require a backend, database, secure authentication, role permissions, and API integrations.
